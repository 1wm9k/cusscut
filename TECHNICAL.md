# CussCut: техническое описание

Этот файл предназначен для продолжения разработки проекта без повторного изучения всей кодовой базы.

## Назначение

CussCut — консольная программа для поиска нецензурной речи и заглушения найденных интервалов в аудио и видео.

Основной поток:

```text
входной файл
  -> FFmpeg извлекает аудио
  -> faster-whisper распознаёт слова и таймкоды
  -> словарь выбирает слова для цензуры
  -> FFmpeg применяет volume-фильтры
  -> FFmpeg собирает итоговый файл
```

## Файлы

- `cli.py` — аргументы CLI, поиск входных файлов, построение плана, загрузка модели и пакетный цикл.
- `processor.py` — FFmpeg, таймкоды, фильтры, кеш распознавания, сборка результата.
- `test_cli.py` — тесты CLI-плана, output-папки, коллизий, dry-run и пропусков.
- `test_processor.py` — тесты словаря, интервалов, confidence, кеша и аудиорезультата.
- `pyproject.toml` — метаданные пакета, зависимости и entry points.
- `requirements.txt` — runtime-зависимости для Docker.
- `requirements-dev.txt` — editable-установка с тестовыми и build-зависимостями.
- `.github/workflows/ci.yml` — тесты и проверка сборки.
- `.github/workflows/publish.yml` — публикация в PyPI через Trusted Publishing.
- `README.md` — пользовательская документация.

## Runtime

Минимальные требования:

- Python 3.10+;
- FFmpeg и FFprobe в `PATH`;
- `faster-whisper>=1.2,<2`.

Whisper загружается лениво: dry-run и запуск, где все результаты уже существуют, не импортируют модель. Модель создаётся один раз на пакет файлов.

По умолчанию:

- модель: `small`;
- устройство: `cpu`;
- compute type на CPU: `int8`;
- язык: `ru`;
- word timestamps: включены;
- VAD: включён.

Модель хранится в кеше Hugging Face. Это кеш модели, отдельно от кеша распознанных таймкодов CussCut.

## Обработка аудио

Для нового распознавания создаются два временных WAV:

- mono 16 kHz для Whisper;
- stereo 44.1 kHz для цензуры.

При попадании в transcription cache Whisper WAV не создаётся: извлекается только полный WAV для рендера.

Цензура выполняется FFmpeg volume-фильтрами. Интервалы объединяются до построения фильтра. Список фильтров записывается во временный `.ffscript`, чтобы не упираться в лимит длины командной строки Windows.

Если совпадений нет и расширение результата совпадает с исходным, исходный файл копируется без перекодирования.

## Видео и потоки

Для видео:

- первая видеодорожка копируется;
- цензурированная аудиодорожка становится первой;
- дополнительные аудиодорожки сохраняются;
- дополнительные аудиодорожки копируются без перекодирования;
- субтитры, data/attachment streams и metadata передаются в итоговый файл, если контейнер их поддерживает;
- результат временно пишется в той же output-папке и только после успешного FFmpeg переименовывается в конечное имя.

Итоговый контейнер для видео — MP4. Некоторые исходные потоки могут быть несовместимы с MP4; для таких файлов нужен отдельный режим вывода в MKV.

## Словарь

Встроенный словарь находится в `processor.py` в `DEFAULT_WORDS`.

Внешний словарь полностью заменяет встроенный. Поддерживаются режимы:

- `substring` — поиск подстроки;
- `prefix` — совпадение в начале слова;
- `exact` — полное совпадение.

Перед сопоставлением применяется Unicode NFKC, нижний регистр и замена `ё` на `е`.

## Cache

Параметр:

```text
--cache-dir PATH
```

Для каждого исходного файла создаётся JSON с хешем пути. Ключ кеша зависит от:

- абсолютного пути;
- размера файла;
- `mtime_ns`;
- имени модели;
- языка.

Словарь, padding, volume и fade в ключ не входят намеренно: они применяются после распознавания.

Если кеш повреждён или ключ не совпадает, файл распознаётся заново. Ошибка записи кеша не должна ломать основную обработку.

## PyPI и CI/CD

Базовая версия хранится в `pyproject.toml`:

```toml
version = "0.1.0"
```

`ci.yml` запускается на push и pull request, ставит FFmpeg, выполняет тесты на Python 3.10–3.12 и проверяет сборку.

`publish.yml` запускается на каждый push в `main`. Перед сборкой он создаёт уникальную PEP 440 версию:

```text
base_version.postGITHUB_RUN_NUMBER
```

Например:

```text
0.1.0.post12
```

Это нужно, потому что PyPI не принимает повторную загрузку одного и того же номера версии.

Для новой основной версии нужно изменить `version` в `pyproject.toml`, например на `0.2.0`. Следующий push опубликует `0.2.0.postN`.

Trusted Publisher PyPI настроен на:

- project: `cusscut`;
- owner: `1wm9k`;
- repository: `cusscut`;
- workflow: `publish.yml`;
- GitHub environment: `pypi`.

API-токены в репозитории не хранятся.


## Ограничения и будущие задачи

- Автоматическое определение языка ещё не является основным режимом.
- Для очень большого количества интервалов filter script уже используется, но сложные контейнеры могут требовать MKV вместо MP4.
- Длительная обработка видео зависит от скорости FFmpeg, диска и CPU/GPU.
- Confidence threshold применяется только когда Whisper возвращает probability для слова.
- Нужно поддержать отдельный выбор аудиодорожки, если в файле несколько языков.
- Стоит добавить интеграционные тесты для MKV, субтитров и нескольких аудиокодеков.
